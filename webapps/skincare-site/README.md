# Skincare Advisor

This simple website captures an image from your webcam and provides a basic skincare product recommendation. The recommendation is generated by analyzing the average color of the captured image as a very rough approximation of your skin condition.

**Usage**
1. Open `index.html` in a web browser that supports webcam access.
2. Allow camera permissions when prompted.
3. Click **Capture** to analyze your face and view the suggested skincare product.

The suggestions are for demonstration purposes only and are not medical advice.
